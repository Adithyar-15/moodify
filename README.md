# Project Description

**MOODIFY is an AI-powered Object Emotion Clinic that gives completely unnecessary therapy to everyday objects.** 

Upload an image, and our AI detects the object using object detection technology. MOODIFY then assigns the object a completely imaginary personality, mood, and emotional problem before sending it to **Dr. MOODIFY**, a highly questionable banana therapist.

The patient receives a therapy session and an official prescription that is absolutely not medically useful. 😭

# The Problem (that doesn't exist)

Everyday objects are silently suffering.

Your chair has been supporting people for years without receiving a single compliment. Your bottle has been repeatedly thrown into bags. Your laptop is exhausted from carrying your academic career.

Unfortunately, nobody has been providing emotional therapy to these objects.

Until now.

# The Solution (that nobody asked for)

MOODIFY uses AI object detection to identify an object from an uploaded image.

After detection, the system:

* 🎯 Identifies the object using AI.
* 🎭 Assigns the object a completely imaginary personality.
* 😊 Diagnoses its current emotional condition.
* 💬 Generates what the object supposedly wants to say.
* 🔊 Reads the diagnosis using text-to-speech.
* 🛋️ Sends the object to the MOODIFY Therapy Department.
* 🍌 Introduces the patient to Dr. MOODIFY, an extremely unqualified banana therapist.
* 🧾 Provides a completely useless medical prescription.

The object learns nothing, but somehow leaves emotionally validated.

# Implementation

## How It Works

### Step 1: Upload a Patient

The user uploads an image containing an everyday object.

### Step 2: AI Object Detection

The COCO-SSD AI model analyzes the image and detects the most confident object.

### Step 3: Emotional Diagnosis

MOODIFY checks the detected object against a custom mood database and generates:

* Object name
* Personality
* Mood
* Funny dialogue

### Step 4: Voice Diagnosis

The browser's Web Speech API reads the emotional diagnosis aloud with different speech settings based on the object's personality.

### Step 5: Therapy Department

The detected object is saved temporarily using Local Storage and transferred to the MOODIFY Therapy Room.

### Step 6: Therapy Session

Dr. MOODIFY, the banana therapist, conducts a completely questionable therapy conversation with the object.

### Step 7: Prescription

After therapy, the patient receives an official MOODIFY prescription containing useless but emotionally supportive advice.
